# Brian's Brain Simulation

A simple web application that simulates Brian's Brain, a cellular automaton.

## Setup

1.  **Clone the repository (or create the files as listed).**
2.  **Install Node.js and npm** if you haven't already.
3.  **Install dependencies:**
    ```bash
    npm install
    ```

## Running the Application

1.  **Build the TypeScript code:**
    ```bash
    npm run build
    ```
    This will compile `script.ts` into `script.js`.

2.  **Start the local server:**
    ```bash
    npm start
    ```
    This command will first build the TypeScript and then start a local development server. It should automatically open the `index.html` page in your default web browser.

    Alternatively, if you have already built the code, you can just run:
    ```bash
    npm run serve
    ```

## File Structure

-   `index.html`: The main HTML file.
-   `style.css`: CSS styles for the application.
-   `script.ts`: TypeScript code for the Brian's Brain logic.
-   `script.js`: Compiled JavaScript code (generated by `tsc`).
-   `tsconfig.json`: TypeScript compiler configuration.
-   `package.json`: Project metadata and dependencies.
-   `README.md`: This file.
